# jhayron-perez.github.io

Personal academic website for Jhayron S. Pérez-Carrasquilla.

## Publish with GitHub Pages

1. Create or use the repository `jhayron-perez/jhayron-perez.github.io`.
2. Upload the contents of this folder to the repository root.
3. In the repository’s **Settings → Pages**, select **Deploy from a branch** and choose `main` and `/ (root)`.

The site uses no build step: GitHub Pages serves `index.html` directly.
